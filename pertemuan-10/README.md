# Pertemuan-10

saya melakukan hal sebagai berikut untuk P10:

1. menyalin artefak P9 sebagai baseline P10.
2. menyiapkan laragon dan pertemuan-10.
3. mencoba akses phpmyadmin melalui alamat http://localhost/phpmyadmin.
4. mengecek 8 input dan name tiap input sebagai kebutuhan data yang akan disimpan.
5. hasil pengecekan 8 input sudah dipetakan data yang sesuai, jadi ke 8 input tersebut akan diwakili oleh 1 field atau kolom di tabel MySQL.
6. ada 2 input checkbox name="minat[]", tujuannya mengelompokkan input tersebut dengan nama yang sama, yaitu minat, sehingga nilainya bisa beberapa.
7. menentukan nama basis data dan nama tabel dengan bentuk db_pwd_nim dan tbl_kontak_nim.
8. menentukan nama kolom/field, tipe data, batasan penyimpanan untuk tiap input.
9. walaupun terdapat 8 input pada form yang dibuat juga 8 kolom, untuk kasus form kontak, maka perlu ditambahkan 1 kolom baru dengan nama id sebagai primary key auto increment.
10. penentuan akhir struktur tabel final yang akan digunakan untuk formulir kontak.
